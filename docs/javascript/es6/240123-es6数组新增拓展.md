# es6数组新增方法

## Array.from()

将类数组对象或可迭代对象转换成真正的数组

let divs = document.querySelectorAll('div');
let divArray = Array.from(divs);

let set = new Set([1, 2, 3, 4, 5]);
let arrFromSet = Array.from(set); // [1, 2, 3, 4, 5]

## Array.of()

定义一个指定参数的新数组

## find() 和 findIndex()

查找数组中符合条件的第一个元素和第一个元素对应的索引

## includes()

检查数组是否包含某个元素
