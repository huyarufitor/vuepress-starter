## 指数运算符

### ** 

- 2**2，就是2的2次方，2**4，就是2的4次方

### 2**3**2 计算顺序

右结合，多个指数运算符连用时，是从最右边开始计算的。相当于 2**(3**2)

### **=

a **= 2  相当于  a=a*a;
a **= 3  相当于  a=a*a*a;

## 链判断运算符 ?.

在链式调用的时候判断，左侧的对象是否为null或undefined，如果是的，就不再往下运算，而是返回undefined。

### 使用场景1

当一个对象有好几层时，要拿到最深层的对象属性的值，一般安全考虑都会一层层判断过去，直到最后一层，比如

```javascript
const message = {
    body:{
        user:{
            firstname:'fitohu'
        }
    }
}
const firstname = (message && message.body && message.body.user && message.body.firstname) ||'takawa'
```

这样就会判断好几次，如果层数够多，就要写很多。
所以有了?.

```javascript
const firstname = (message?.body?.user?.firstname)||'taka';
```

### 使用场景2

判断对象是否存在

```javascript
a?.b
// 等同于
a == null ? undefined : a.b

a?.[x]
// 等同于
a == null ? undefined : a[x]

a?.b()
// 等同于
a == null ? undefined : a.b()

a?.()
// 等同于
a == null ? undefined : a()
```

### 注意
（1）?.是一种短路机制，只要前面的条件满足，即拿到null/undefined,就不会再继续往下执行
（2）括号的影响
(a?.b).c  不管a对象有没有b，都会继续往下执行，拿c，所以一般不建议加上括号，除非你知道你在干嘛；
（3）报错场合

```javascript
// 构造函数
new a?.()
new a?.b()

// 链判断运算符的右侧有模板字符串
a?.`{b}`
a?.b`{c}`

// 链判断运算符的左侧是 super
super?.()
super?.foo

// 链运算符用于赋值运算符左侧
a?.b = c
```

(4)?.不能跟十进制数
比如：foo?.3:2 会变成三元运算符，而不是链式判断。

## null判断运算符??
场景： 读取对象属性时，如果某个属性的值为null或者undefined时，指定默认值
通常：
```javacript       
const response = {
    setting:{
        // headerText:''
        headerText:'hell,it's me'
    }
}
const headerText = response.settings.headerText || 'Hello, world!';
```

缺点：用||时，如果headerText 是空字符串、0、false时，也会用默认值；
现在：用??代替；

```javacript
const response = {
    setting:{
        // headerText:''
        headerText:'hell,it's me'
    }
}
const headerText = response.settings.headerText ?? 'Hello, world!';
```

注意：??和||、&&都是逻辑运算符，一起用的时候要加上（）,不然会报错；
