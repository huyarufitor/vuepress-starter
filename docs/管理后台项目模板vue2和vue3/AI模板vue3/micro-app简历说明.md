# 音乐内容运营管理平台前端子应用
## 项目描述
  作为核心前端参与 qiankun 微前端子应用开发，负责音乐内容与资源运营后台建设，覆盖歌曲/元歌曲、歌单、标签、Banner、教程、音色音效、节奏、固件版本、排行榜、举报及权限管理等核心模块。
## 技术栈
  Vue3、TypeScript、Pinia、Vue Router、Element Plus、Vite、Axios、qiankun、Sass

## 项目亮点
  - 主导微前端接入方案，完成父子应用状态同步、菜单驱动动态路由注册、国内/海外业务切换与缓存兜底。
  - 抽象 ProTable / Pagination / SubmitForm 等通用组件，统一请求封装、错误处理与请求取消，提升团队复用效率。
  - 支撑文件上传、音频预览、拖拽排序、批量导入、多语言配置等复杂运营场景，保障后台高频迭代稳定交付。

## 项目难点
  - 微前端场景下父应用菜单、权限、用户态和子应用路由的动态同步与兼容。
  - 菜单配置到页面组件的动态映射注册，要求运行时可扩展且避免重复路由。
  - 国内/海外两套业务配置与接口基址并存，需要保证业务隔离和切换一致性。


## 项目贡献
1. 负责音乐内容运营管理后台前端开发，基于 Vue3 + TypeScript + Pinia + Element Plus + Vite 搭建微前端子应用，承接歌曲/元歌曲、歌单、标签、Banner、教程、资源包、排行榜、固件版本等核心运营模块建设。
2. 负责后台通用能力设计与落地，包括动态菜单路由注册、权限菜单适配、父子应用状态同步、国内/海外业务切换、统一请求封装、通用表格/表单组件封装，提升多业务模块复用性与迭代效率。
3. 负责复杂运营交互实现与体验优化，支持文件上传、音频预览、拖拽排序、批量导入、多语言配置、内容审核与版本配置等场景，保障内容管理流程稳定可用。
