## 如何保证同时请求5个接口，按照顺序输出结果？

（1）使用async/await
使用async/await可以使异步代码看起来更像同步代码，可以按顺序等待每个异步操作完成。
缺点：无法同时请求
（2）使用Promise.all()

```javascript
// 假设这是你的 API 请求函数，每个函数都返回一个 Promise
function requestApi(url) {
    return new Promise((resolve, reject) => {
        fetch(url)
            .then(response => response.json())
            .then(data => resolve(data))
            .catch(error => reject(error));
    });
}

// 定义要请求的 URL 列表
const urls = [
    'https://api.example.com/data1',
    'https://api.example.com/data2',
    'https://api.example.com/data3',
    'https://api.example.com/data4',
    'https://api.example.com/data5'
];

// 使用 Promise.all() 执行所有请求
Promise.all(urls.map(url => requestApi(url)))
    .then(results => {
        console.log('结果按顺序输出：');
        results.forEach(result => console.log(result));
    })
    .catch(error => console.error('发生错误：', error));
```

优点：当所有Promise都解析成功时，它会返回一个新的Promise,该Promise 在回调函数中处理所有请求的结果。如果任何一个Promise拒绝，Promise.all()返回的Promise也会立即拒绝，且回调函数不会被调用。

缺点：前后接口没有关联关系

## 高阶函数的定义是什么？什么时候用到它？

就是一个函数 可以接受 别的函数作为参数，比如：

```javascript
function add(x, y, f) {
    return f(x) + f(y);
}
```

一般在函数式编程或者现代编程范式中。
（1）函数柯里化：将一个多参数的函数转化为一系列单参数的函数
柯里化是一种转换，将f(a,b,c)转换为可以被f(a)(b)(c)的形式调用。能让我们更容易地获取部分应用函数。
（2）函数组合：通过组合不同的函数，构建更复杂的函数。例如，可以将两个函数连接起来，使得第一个函数的结果成为第二个函数的输入。

```javascript
function square(x) { return x * x; }
function double(x) { return x * 2; }

const squareThenDouble = x => double(square(x));
console.log(squareThenDouble(3)); // 输出18
```

(3)数组处理函数：Array类型的方法，如map、filter、reduce、foreach,都是高阶函数的例子

```javascript
const numbers = [1, 2, 3, 4, 5];
const squaredNumbers = numbers.map(n => n * n);
console.log(squaredNumbers); // 输出 [1, 4, 9, 16, 25]
```

(4)事件处理程序：事件处理器通常使用高阶函数

```javascript
button.addEventListener('click', function(event) {
    // 处理点击事件
});
```

## 滑动窗口的题目-leetcode3 无重复字符的最长子串

给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度

示例 1:

输入: s = "abcabcbb"
输出: 3
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。
示例 2:

输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
示例 3:

输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。

提示：

0 <= s.length <= 5 * 104
s 由英文字母、数字、符号和空格组成

思路：滑动窗口，其实就是一个队列，进入这个队列为abc,满足题目，但是再进入一个a,队列变成了abca,不满足要求。所以要移动队列，将左边的元素移出，直到满足题目要求！一直维持这样的队列，找出队列出现最长的长度时候，求出解。
复杂度：o(n) [空间和时间都是]

判断重复字符：用到哈希集合，Python中的set,javascript中的Set;在左指针向右移动的时候，我们从哈希集合中移除一个字符，在右指针向右移动的时候，我们往哈希集合中添加一个字符。

代码：

```javascript
/**
 * @param {string} s
 * @return {number}
 */
var lengthOfLongestSubstring = function(s) {
    const occ = new Set();//哈希集合，记录每个字符是否出现过
    const n = s.length;
    let rk = -1,ans = 0;// 右指针，初始值为-1；相当于我们再字符串的左边界的左侧，还没有开始移动
    for(let i=0;i<n;++i){
        if(i!=0){
            occ.delete(s.charAt(i-1));//左指针向右移动一格，移除一个字符；
        }
        while(rk+1 <n && !occ.has(s.charAt(rk+1))){
            // 不断地移动右指针
            occ.add(s.charAt(rk+1));
            ++rk;
        }
        ans = Math.max(ans,rk-i+1);//第i到rk个字符是一个极长的无重复字符子串。
    }
    return ans;
};
```

解法二：暴力解法，时间复杂度O(n^2)

1、靠考虑字符串为空的情况；
2、字符串均为重复字符串的情况
3、测试其他常规输入
