# 事件循环机制

- 同步任务
- 异步任务
    - 微任务：process.nextTick、Promise.then(catch finally)、MutationObserver
    - 宏任务：script、setTimeout、setInterval、setImmediate、I/O、UI rendering

微任务是后面提出的新的异步任务，在执行每一个宏任务之前，程序都会先检测是否有当次事件循环还没有被执行的微任务，如果有，则清空本次的微任务后再去执行下一个宏任务。

## 执行流程

1. 同步代码从上到下顺序执行 ，运行过程中注册本次微任务和后续宏任务；
2. 本次同步代码执行完后，检查一下`当前微任务队列是否有注册微任务`，有，就优先执行微任务队列中注册的微任务；
3. `当前注册的微任务`中有微任务和后续宏任务，则会把宏任务和微任务注册到任务队列。
4. 直到把`下一个宏任务开始前`的所有微任务都执行完
5. 开始执行下一个宏任务，重复2-4步骤

## 总结

当前代码产生的微任务，会在下一个宏任务执行前优先执行。
当前同步任务 --> 当前同步任务产生的微任务 --> 下一个需要执行的宏任务
