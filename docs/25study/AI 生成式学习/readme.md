## 写一个曲谱报错页面

./tailWindcssExample.html
分析以下内容，并将其转化为清晰美观的可视化 HTML 网页：
1、用户在弹唱页面点击【曲谱信息报错】按钮打开「曲谱信息报错」页面，不同机型表现不一致，具体如上图
2、「曲谱报错页面」分为：错误类型（必选）和错误描述（必填）两部分，错误类型为多选

● 错误类型（必选）
a 曲谱信息错误
b 和弦标注错误/缺漏
c 歌词错误
d 领唱错误
e 旋律跟唱错误
f 自动鼓机/转调错误
g 动作提示错误
h 其他
● 错误描述（必填）

3、用户提交后在管理后台可查询，查询路径：歌曲-歌曲报错
新增记录反馈用户所连接的机型，未连接则为字段“无”
4、由于错误类型为多选，用户进行多选时沿用现有逻辑，生成多条记录以区分错误类型
5、选择【跳转曲谱】时，能够跳转到对应的和弦/多维曲谱编辑页，返回时保留上一步操作，包括筛选和页码

## 写一个 音乐人 品牌展示网站

./doubaomusicExample.html

请创建一个为独立音乐人打造的个人品牌展示型网站模板，包含音乐作品试听、现场演出日程、乐迷互动留言板、专辑购买入口、社交媒体链接等核心模块。页面风格需突出个性与艺术气质，可选择复古磁带风、街头涂鸦风，或带有暗黑浪漫气息的夜店光感风格，整体设计应有粗颗粒纹理背景、霓虹标题、低饱和色调搭配高对比度组件。网站首页应能快速吸引粉丝注意力，支持嵌入 Spotify / Apple Music 播放器，音乐页面提供分专辑/单曲浏览，演出页面需展示时间、地点、购票链接。“创作幕后”板块用于展示歌词草稿、录音花絮、灵感来源等内容，增强粉丝共鸣感与粘性。建议使用卡片式布局与横向滑动组件增强浏览体验，整体兼顾移动端与桌面端适配。
