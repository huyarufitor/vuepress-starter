# shell 那些变量 $  代表什么？

为什么整理这个？
--- 因为线索后台的项目，每次构建测试环境都要手动上去拉代码，所以写个脚本，自动拉一下代码

## $$/$!/$?/$-/$*/$@/$#/$0/$1/$2/..../$10

### $$  shell processID

### $!  shell 最后运行的命令的结束代码（返回值）

### $?  最后运行的命令的结束代码（返回值）

### $-  使用Set命令设定的Flag一览

### $* 所有参数列表

如 "$*" 用「"」括起来的情况，以"$1 $2 ... $n"的形式输出所有参数

### $@ 所有参数列表

如 "$*" 用「"」括起来的情况，以"$1" "$2" "$3" ... "$n" 的形式输出所有参数。

### $# 添加到shell的参数个数

比如 ./test.sh a b c 的$#结果是 3，因为有3个参数。

### $0 shell 本身文件名

### $1 添加到shell的第一个参数 

同理 $2 $3 $4 $5 分别是第二个参数、第三个参数、第四个参数、第五个参数
