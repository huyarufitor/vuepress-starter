## 代码格式化

1. Vetur
   语法高亮，Emmet支持，格式化代码，错误检查，自动补全
2. Prettier - Code formatter  
   代码格式化，团队的代码风格的规范或统一，例如每行最大长度，单引号还是双引号，等号左右空格，使用 tab 还是空格
3. ESlint  
   代码检查，检查代码是否符合规范
4. Beautify css/sass/scss/less --格式化css、scss、less文件格式
5. Auto Close Tag --自动闭合标签
6. Auto Rename Tag --自动修改结束标签的名字

## 前端相关

1. Volar --vue3的语法高亮、Emmet支持、格式化代码、错误检查、自动补全 --vue  language Features(volar)
2. Vetur --vue2的语法高亮、Emmet支持、格式化代码、错误检查、自动补全
3. Beautify css/sass/scss/less --格式化css、scss、less文件格式
