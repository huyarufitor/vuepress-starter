# 01

## 什么是vue/对vue的理解

### vue是创建单页面应用的渐进式web框架

## vue核心特性

### 数据驱动视图（MVVM：M:Model V:View VM:ViewModel）、双向数据绑定

View：视图层，页面上看到的东西，也就是UI展示的HTML；
Model：模型层，处理业务逻辑，负责与服务端交互
ViewModel：视图模型层，连接桥梁；
自定义指令在模板中使用前必须先注册
### 组件化

每个.vue文件都是一个组件，优点是可复用、降低系统耦合、提高可维护性；

### 指令系统 Directives

当表达式的值改变时，产生对应影响，作用于DOM
常用指令：v-if/v-show/v-else/v-bind/v-on/v-model
自定义指令：v-xxxx(自定义指令在模板中使用前必须先注册)

### vue与传统的区别

1、jquery是直接操作DOM，Vue是通过操作数据更新视图

### Vue和React对比

#### 异
1、diff算法不同。vue使用双向指针，边对比，边更新DOM；React使用diff队列保存需要更新哪些DOM，得到Patch树，再统一处理批量更新DOM；
2、组件通信不同。vue子->父 组件传值：事件（$emit）、回调函数、refs/$parent/$children
3、数据变化的实现原理不同。vue使用的是不可变数据；react使用的是可变的数据。
4、Vue有指令系统、React有reacthooks

#### 同
1、都有虚拟DOM 
2、都有组件化思想
3、都支持服务器端渲染
4、都是数据驱动视图
5、都有支持native的方案Vue:weex;React:React Native
6、都有自己的构建工具：Vue: Vue-cli、React: Create React App
7、都有对应的状态管理：Vue:Vuex、React: Redux
