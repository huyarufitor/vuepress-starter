# nextTick 是什么？

等待下一次 DOM 更新刷新的工具方法。
· 类型

```javascript
 function nextTick(callback?: () => void): Promise<void>
 ```

当在vue中更改响应式状态时，最终的DOM 更新不是立刻生效的，而是进入一个等待队列中，直到下一个“tick”才一起执行，这样是为了确保每个组件无论发生多少状态改变，都只执行一次更新。
简单来说，就是如果想用最新的 DOM操作一些数据，可以在nexttick回调函数里操作，这样就是用最新的DOM；

## 什么时候使用nextTick？

1、created 钩子函数进行的DOM操作一定要放在Vue.nextTick回调函数中
--原因：created的时候，DOM没进行任何渲染，操作DOM就是没用的。在mounted函数中，所有的DOM挂载已完成。
比如：在created通过this.$refs中操作dom,会报错，加上$nexttick就不会报错；

```javascript
<template>
 <a ref="aa" href="">afafa</a>
</template>
 created() {
        const that = this;
        // that.$nextTick(() => {
            const a = that.$refs.aa as any;
            a.innerHTML = 'cretae';
        // });
    }
 ```

2、更改数据后当你想立即使用 js 操作新的视图的时候需要使用nextTick(其实第一种也算是第二种情况的细分)
3、在使用第三方插件时，如果dom元素变化，想要重新应用使用的插件，也要在nextTick中重新执行插件初始化的操作；
